Ember Linux

About this system

A calm, Gentoo-based desktop distribution. Ember provides the installer, the desktop defaults and a coherent visual identity; Portage provides the packages and Gentoo provides the foundation.

Release
Ember Linux 1.0 “Cinder”
Base
Gentoo Linux (stage3, OpenRC)
Desktop
The desktop selected during installation — Openbox by default, with tint2, rofi and picom
Package manager
Portage — emerge, emaint, eselect
Init system
OpenRC
Live details
Run uname -a, emerge --info or open /etc/os-release in a terminal.
