Welcome

Your new system is ready.

Ember is a careful desktop built on Gentoo. This page collects the first few things worth doing: update the system, connect to the network, learn the shortcuts, and find help if something is not right.

FIRST 10 MINUTES

Update the system

Ember ships a consistent snapshot. Sync Portage and rebuild what has changed since the image was made.

$sudo emaint sync -a
$sudo emerge --ask --update --deep --newuse @world

Read the news before a large update: eselect news read.

SOFTWARE

Install what you need

Portage is the package manager. Search, inspect and install without leaving the terminal.

$emerge --search firefox
$sudo emerge --ask www-client/firefox

For package details and reverse dependencies, install app-portage/gentoolkit and use equery.

NETWORK

Get online

NetworkManager is enabled by default. Click the network icon in the panel, or use the text interface if you prefer.

$nmtui

Check the connection with nmcli device status and ping -c 3 gentoo.org.

SERVICES

Turn things on

OpenRC manages services. Add one to the default runlevel, then start it now.

$sudo rc-update add NetworkManager default
$sudo rc-service NetworkManager start
YOUR DESKTOP

Openbox, tint2 and rofi

The panel at the bottom of the screen holds your launchers, open windows, the system tray and the clock. Right-click the desktop for the full application menu.

  • Super+EnterOpen a terminal
  • Super+DApplication finder (rofi)
  • Super+EFile manager
  • Super+BWeb browser
  • Super+WThis welcome page

Window control. Drag the title bar to move, drag an edge to resize. Super + arrows snap a window to a half or maximise it. Alt + Tab cycles windows; Alt + F4 closes one.

Workspaces. There are four named desktops: Main, Web, Work and Media. Switch with Super + 1–4, or move a window with Super + Shift + 1–4.

Change the theme, fonts or panel later with lxappearance, obconf and tint2conf if those tools are installed.

HELP

When something is not right

  • Installer logthe log path is shown on the installer's error page; copy it before closing the live session.
  • Terminalpress Ctrl+Alt+F2 for a text console, Ctrl+Alt+F7 to return.
  • Boot menuhold Shift (BIOS) or press Esc (UEFI) while booting to reach GRUB.
  • Package problemsread /var/log/emerge.log and run emerge --info for a report.
