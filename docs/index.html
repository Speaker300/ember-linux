The installer is the product

Boring installs, by design.

Ember does the parts of a Gentoo install that are easy to get wrong: the stage3, the partition layout, the bootloader, the desktop session, and a make.conf that matches the machine. The result is still Gentoo.

01

Stage3 without the guesswork

A short guide explains desktop versus minimal, then the installer fetches the current OpenRC tarball from Gentoo mirrors. No frozen snapshot, no hidden profile switch.

02

A desktop choice that is honest

Thirteen choices, from Openbox to GNOME, KDE Plasma, Sway, and i3. The installer offers them; the documentation tells you which one has actually been through QA.

03

A system you can inspect

The target gets a readable make.conf and a post-install report at /var/log/ember-install-report.txt that checks the kernel, GRUB, fstab, services, and desktop setup.

04

Gentoo all the way down

Portage, OpenRC, the Gentoo repository. No second package manager, no private overlay, no fork. You can read and change everything after the reboot.

Evidence, not adjectives

Status without the asterisks.

“Tested” means a complete install from an exact ISO, a disk-only boot, a login, and a network check on the firmware modes claimed. If that has not happened, the row says so.

Four decisions

From USB to a Gentoo system.

The current verified path is deliberately narrow. The full walkthrough covers the choices, the logs, and the first-boot checks.

  1. 1

    Boot the ISO

    BIOS or UEFI. Keep Secure Boot off until the signed chain has passed QA.

  2. 2

    Pick a stage3

    amd64, current OpenRC stage3. Desktop profile for a desktop; minimal for a server.

  3. 3

    Pick a desktop

    Thirteen choices; Openbox is the only one with a completed QA pass. GNOME needs a systemd stage3.

  4. 4

    Install and reboot

    Erase the disk, create a user, install, then boot the disk without the ISO.

Before you start: the normal install is online-only, the erase-disk path deletes every partition on the target, and Secure Boot must stay off. Newer builds add an untested Live CD (offline) option. Read the install guide.

Under the hood

No surprises in the stack.

The installer is opinionated about the base and quiet about the rest. These are the pieces the verified build actually used.

  • BaseGentoo amd64Current stage3, downloaded at install
  • InitOpenRCTested path; systemd only for GNOME, untested
  • InstallerCalamares 3.4Gentoo patches + Ember modules
  • Kernelgentoo-kernel-bin6.18.4 in the verified build
  • BootGRUBHybrid BIOS + UEFI GPT layout
  • NetworkNetworkManagerWired path verified in QEMU
  • SessionLightDM + Openboxtint2, picom, rofi, xterm
  • Storageext4 root512 MiB ESP + 8 MiB BIOS boot
